# SEO Master (AutoSEO)

Web app that audits websites and web apps for SEO issues — and, in a later stage, applies fixes automatically.

**Current stage:** analysis only. See [docs/PLAN.md](docs/PLAN.md) for the roadmap and [CLAUDE.md](CLAUDE.md) for development conventions.

## Getting started

```bash
pnpm install
cp .env.example .env.local   # fill in Supabase / Anthropic / PageSpeed keys
pnpm dev
```
